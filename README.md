# 系统设计互动札记

直接双击 [index.html](index.html) 即可学习。无需服务器、账号、安装依赖或网络。所有课程内容、样式、脚本和 SVG 均在这个文件内。

## 内容与使用

- 覆盖74个主题、32个案例与七组目录。每课为连续阅读：场景、概念原理、图解推导、具体例子、动手探索、适用边界、结论；建议连同实验和复述用10–15分钟学习。
- 新增约4.5万字逐课原创导学，含148条术语解释、74个具体例子。核心正文直接可见；不答题也能完整阅读并标记完成。
- 32个案例默认展示五阶段基线设计，允许比较全部备选方案与代价。222道自测放在文末折叠区域，答错加入错题回顾，答对移出；查看解析不算答对。
- 缓存、队列、库存、分片、哈希环、CAP和视频生命周期有确定性实验。滑块调整命中率、流量和处理能力，按钮推进时间或注入故障；模型假设直接显示。不同课程的实验状态独立，刷新后重置实验。
- 其他主题提供路径逐步展开，支持前后跳转与重置。课内定位导航和自动记录的阅读区段便于回看，不再用阶段标签隐藏正文。
- 新版自动从旧进度迁移：保留完成标记、答案和案例选择，将旧阶段映射到对应阅读区段。原v1记录保留，v2保存失败时仍能在内存中学习并显示提示。
- 本地存储可能因浏览器、访问路径、隐私设置不同而隔离。单文件学习不需要网络；来源链接需要联网。CSP禁止课程运行代码联网，不加载外部字体、图片或库。
- 真实系统的公开做法就近链接到工程原文，另行标注教学例子与模型。内容为原创中文解释，不是原站全文翻译或付费正文复刻。

## Problem Breakdowns 全题覆盖

[查看 32 题覆盖清单与中文笔记](problem-breakdowns/README.md)。每题笔记包含独立概念原理、术语、具体例子、适用边界、实体和接口、五个设计决策及备选代价、自测和来源。每次构建从网页同一份课程数据重新导出，避免网页与笔记分叉。

运行 `npm run check:breakdowns` 可重新核对公开导航、站点地图和逐页链接，验证全部页面状态与本地内容结构，更新 `artifacts/problem-breakdowns-coverage.json` 和笔记。核验失败会返回非零退出码；发现新增题目会列入缺失清单。此检查需联网，课程学习仍可离线。题目覆盖不等于原站文章全文或付费深入内容覆盖。

## 开发

使用 Node.js 20+，本地预览、构建与内容测试没有第三方依赖：

```sh
pnpm dev
```

打开 http://127.0.0.1:5173。启动时自动构建；修改 `src/` 后自动重新构建，刷新浏览器即可查看。按 Ctrl+C 停止；端口被占用时可运行 `PORT=5174 pnpm dev`。也支持 `npm run dev`。

单独构建与测试：

```sh
npm run build
npm test
```

源文件职责：

- `src/content/`：原始目录、课程数据与来源。`reading-notes.txt`逐课维护原创正文，`reading.mjs`将其组成有序内容区块并校验完整性。每条记录为课程ID、导语、两条术语、原理、机制、例子、边界与探索指引。
- `src/shell.html`、`src/styles.css`：文档与页面外观。
- `src/app.js`：连续正文渲染、课内导航、局部交互更新、v1到v2进度迁移、错题与无障碍。
- `src/experiments.js`：独立确定性教学模型。
- `scripts/build.mjs`：验证完整目录与前置关系，生成单文件 HTML 和便于审阅的课程 JSON，调用 `scripts/export-notes.mjs` 同步32份案例笔记。

浏览器验收需可用的 Playwright 模块与 Chromium/Chrome。可在开发环境安装 Playwright 后运行 `npm run test:browser`，或使用已有模块：

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs CHROME_PATH=/absolute/path/to/chrome npm run test:browser
```

macOS 已安装 Chrome 时可省略 `CHROME_PATH`。没有系统浏览器时先通过 Playwright 安装 Chromium。

测试在独立无界面浏览器中打开 `file://` 并关闭网络。覆盖74课的无答题阅读与完成、320条案例备选路径、222道自测、局部DOM更新、滑块键盘与焦点、视频失败恢复、四种旧阶段迁移、损坏或拒绝的存储、错题回顾，以及全部课程在320/390/768像素下的横向溢出。报告和截图保存在 `artifacts/`。

## 教学边界

演示中的流程与数值有意简化，不是实际运行的数据库、消息集群、支付网关或生产级 OT/CRDT。实际系统分析区区分公开工程事实与教学推演；其他品牌案例是设计练习，不声称描述公司的真实内部部署。
