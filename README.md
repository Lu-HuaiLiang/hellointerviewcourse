# 系统设计互动札记

直接双击 [index.html](index.html) 即可学习。无需服务器、账号、安装依赖或网络。所有课程内容、样式、脚本和 SVG 均在这个文件内。

## 内容与使用

- 以 2026-09-13 的 Hello Interview 系统设计侧边目录为主题清单，包含 74 个主题、32 个设计案例、222 道判断题与 160 个案例决策。
- 中文讲解、问题与图示为原创互动导学，覆盖各主题的核心概念与设计边界，不是原站文章的全文翻译，也不复刻付费材料。
- 每课按照场景、演示、判断、总结学习，全部互动通过按钮完成，无需输入文字。每道题都可以查看解析、重新判断。
- 缓存、分片、哈希环、CAP、库存竞争和队列有可重复操作的确定性小实验，教学假设显示在实验下方。
- “推荐下一课”先补前置知识；目录允许自由跳章。已完成由用户手动标记，不假装等于考试成绩。
- 错题在答错时加入，答对后移出；查看解析不算答对。刷新保存阶段、题目选择、案例决策与完成标记。小实验状态仅保留在当前打开的页面内。
- 进度使用浏览器本地存储，不同浏览器、文件路径或隐私模式可能不共享。存储不可用时显示提示并继续在内存中运行。清除浏览器数据会清除进度。
- 参考链接需联网打开，但学习本身不需要。CSP 禁止课程脚本联网；不加载在线字体、图片、库或模型。

## 视觉参考

参考本地 learnAndRecord 的 `app/globals.css`：暖纸色 `#f5f3ee`、墨黑 `#202124`、薄荷绿 `#7dc8b1`、陶土橙 `#e36f3c`。正文沿用 Georgia / Noto Serif SC / Songti SC 衬线字体栈，标题使用无衬线字体，编号与辅助标注使用等宽字体。系统会选择设备已有字体，不下载字体。

## 开发

使用 Node.js 20+，构建与内容测试没有第三方依赖：

```sh
npm run build
npm test
```

源文件职责：

- `src/content/`：原始目录快照、完整课程数据、来源与数据构造函数。
- `src/shell.html`、`src/styles.css`：文档与页面外观。
- `src/app.js`：导航、课程交互、持久化、错题与无障碍。
- `src/experiments.js`：独立确定性教学模型。
- `scripts/build.mjs`：验证完整目录与前置关系，生成单文件 HTML 和便于审阅的课程 JSON。

浏览器验收需可用的 Playwright 模块与 Chromium/Chrome。可在开发环境安装 Playwright 后运行 `npm run test:browser`，或使用已有模块：

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs CHROME_PATH=/absolute/path/to/chrome npm run test:browser
```

macOS 已安装 Chrome 时可省略 `CHROME_PATH`。没有系统浏览器时先通过 Playwright 安装 Chromium。

测试在独立无界面浏览器中打开 `file://` 并关闭网络。覆盖所有章节、全部练习反馈、所有案例备选路径、刷新恢复、拒绝/损坏的存储、错题流程、键盘标签页和手机布局。报告和截图保存在 `artifacts/`。

## 教学边界

演示中的流程与数值有意简化，不是实际运行的数据库、消息集群、支付网关或生产级 OT/CRDT。实际系统分析区区分公开工程事实与教学推演；其他品牌案例是设计练习，不声称描述公司的真实内部部署。
